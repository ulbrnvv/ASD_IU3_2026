# Отчет по задаче 2: Индекс первого вхождения
## 1. Идея решения и структура данных
**Идея:** Линейный поиск заданного элемента `x` в массиве слева направо. При первом совпадении с текущим элементом фиксируется его индекс, после чего поиск прерывается. Если элемент не найден по завершении прохода, возвращается `-1`.

**Структура данных:** Стандартный одномерный массив `int[]`. Позволяет обращаться к элементам по индексу за $O(1)$, что обеспечивает оптимальную скорость обработки данных.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
int resultIndex = -1;
for (int i = 0; i < n; i++) {
        if (array[i] == x) {
resultIndex = i;
        break;
        }
}
```
В худшем случае (когда искомый элемент находится в самом конце массива или полностью отсутствует) цикл выполняет все $n$ итераций. Операции сравнения выполняются за $O(1)$.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для индекса и искомого значения).
## 3. Ручные тесты
1. Элемент присутствует в массиве:
* Вход: 5 2 | 10 20 20 30 40 | 20
* Выход: 1
* Значимость: Проверяет корректность возврата индекса именно первого вхождения элемента.
2. Элемент отсутствует в массиве:
* Вход: 4 2 | 1 2 3 4 | 99
* Выход: -1
* Значимость: Проверяет граничный случай, когда элемент не найден, и программа корректно возвращает -1.
