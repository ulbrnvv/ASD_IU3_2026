# Отчет по задаче 11: Ближайший к среднему
## 1. Идея решения и структура данных

**Идея:** Двухпроходный алгоритм. На первом проходе вычисляется общая сумма элементов и находится среднее арифметическое (которое может быть дробным числом типа `double`). На втором проходе по массиву ищется элемент, у которого модуль разности между его значением и средним арифметическим (`Math.abs(array[i] - average)`) является минимальным. При наличии нескольких элементов с одинаковой минимальной разницей выбирается тот, который встречается раньше (имеет меньший индекс).

**Структура данных:** Стандартный одномерный массив `int[]`. Обеспечивает эффективный доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
long sum = 0;
for (int i = 0; i < n; i++) {
    sum += array[i];
}
double average = (double) sum / n;

int closestIndex = 0;
double minDifference = Math.abs(array[0] - average);

for (int i = 1; i < n; i++) {
double currentDifference = Math.abs(array[i] - average);
    if (currentDifference < minDifference) {
        minDifference = currentDifference;
        closestIndex = i;
    }
}
```
Алгоритм совершает два последовательных независимых цикла по $n$ итераций (один для подсчета суммы, второй для поиска ближайшего элемента). Это дает $2n$ операций, что после отбрасывания константы соответствует линейной асимптотике $O(n)$.
Дополнительная память: $O(1)$ (используется фиксированное число переменных для суммы, среднего, минимальной разницы и искомого индекса).
## 3. Ручные тесты
1. Стандартный массив с единственным ближайшим элементом:
* Вход: 4 | 1 2 3 10
* Выход: 3
* Значимость: Проверяет корректность расчета дробного среднего и нахождения элемента с минимальной абсолютной разницей.
2. Массив с равноудаленными элементами от среднего:
* Вход: 2 | 2 4
* Выход: 2
* Значимость: Проверяет условие задачи о выборе первого по индексу элемента в случае равенства минимальных разниц (строгое неравенство currentDifference < minDifference оставляет первый найденный).
