# Отчет по задаче 7: Второй максимум
## 1. Идея решения и структура данных
**Идея:** Однократный линейный проход по массиву с поддержанием двух переменных (`max1` и `max2`) для отслеживания наибольшего и второго по величине элементов. При встрече элемента, превышающего текущий максимальный, старый максимум сдвигается на позицию второго, а в первый записывается новое значение.

**Структура данных:** Стандартный одномерный массив `int[]`. Позволяет обращаться к элементам по индексам за $O(1)$ для эффективного сравнения.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
int max1 = Math.max(array[0], array[1]);
int max2 = Math.min(array[0], array[1]);

for (int i = 2; i < n; i++) {
    if (array[i] > max1) {
        max2 = max1;
        max1 = array[i];
    } else if (array[i] > max2) {
        max2 = array[i];
    }
}
```
Цикл выполняется ровно $n - 2$ раза (проход по оставшимся элементам массива). Все условные ветвления и операции присваивания выполняются за константное время $O(1)$, что суммарно дает линейную временную сложность.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для хранения максимумов).
## 3. Ручные тесты
1. Стандартный массив с уникальными числами в разброс:
* Вход: 4 | 10 5 20 15
* Выход: 15
* Значимость: Проверяет корректность обновления обоих максимумов при обнаружении нового наибольшего элемента.
2. Массив с отрицательными числами:
* Вход: 3 | -5 -1 -10
* Выход: -5
* Значимость: Проверяет корректность работы алгоритма с отрицательными значениями (где меньшее по модулю число является большим).
