# Отчет по задаче 8: Фильтрация по знаку
## 1. Идея решения и структура данных
**Идея:** Проход по исходному массиву слева направо с распределением элементов по двум коллекциям: положительные числа сохраняются в один список, отрицательные — в другой. Нулевые значения полностью игнорируются и не включаются ни в один из результатов. Относительный порядок элементов внутри каждой группы сохраняется.

**Структура данных:** Исходный массив `int[]` для входных данных и два динамических списка `ArrayList<Integer>` (`positives` и `negatives`) для раздельного накопления положительных и отрицательных чисел, так как их количество заранее неизвестно.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
List<Integer> positives = new ArrayList<>();
List<Integer> negatives = new ArrayList<>();
for (int i = 0; i < n; i++) {
    if (array[i] > 0) {
        positives.add(array[i]);
    } else if (array[i] < 0) {
        negatives.add(array[i]);
    }
}
```
Алгоритм совершает один линейный проход по всем $n$ элементам массива. Проверки условий и добавление элементов в списки выполняются за константное время $O(1)$.
Дополнительная память: $O(n)$ в худшем случае, так как все элементы массива распределяются по двум дополнительным спискам.
## 3. Ручные тесты
1. Массив со смешанными знаками и нулями:
* Вход: 5 | 0 5 -3 0 2
* Выход: положительные: 5 2, отрицательные: -3
* Значимость: Проверяет корректность фильтрации и гарантирует, что нули не попадают ни в положительные, ни в отрицательные результаты.
2. Массив только с положительными и отрицательными числами (без нулей):
* Вход: 4 | -1 2 -3 4
* Выход: положительные: 2 4, отрицательные: -1 -3
* Значимость: Проверяет сохранение исходного относительного порядка элементов в обеих группах.
