# Отчет по задаче 6: Элементы больше среднего
## 1. Идея решения и структура данных
**Идея:** Двухпроходный алгоритм. На первом проходе вычисляется общая сумма элементов массива и находится их среднее арифметическое. На втором проходе выполняется поиск и подсчет элементов, значения которых строго превышают полученное среднее.

**Структура данных:** Стандартный одномерный массив `int[]`. Позволяет обращаться к элементам по индексам за $O(1)$ и использовать многократный последовательный доступ к данным.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
long sum = 0;
for (int i = 0; i < n; i++) {
    sum += array[i];
}
int average = (int) (sum / n);

int count = 0;
for (int i = 0; i < n; i++) {
    if (array[i] > average) {
        count++;
    }
}
```
Алгоритм совершает два последовательных независимых цикла по $n$ итераций (один для суммы, второй для сравнения со средним). Суммарно это дает $2n$ операций, что после отбрасывания константы соответствует линейной асимптотике $O(n)$.
Дополнительная память: $O(1)$ (используется фиксированное количество скалярных переменных для суммы, среднего и счетчика).
## 3. Ручные тесты
1. Стандартный массив с элементами больше среднего:
* Вход: 4 | 1 2 3 10
* Выход: 1
* Значимость: Проверяет корректность вычисления среднего значения и правильность подсчета элементов, превышающих его.
2. Массив, где все элементы равны между собой:
* Вход: 3 | 5 5 5
* Выход: 0
* Значимость: Проверяет граничный случай, когда элементов, строго больших среднего, нет (строгое неравенство отсекает равные элементы).
