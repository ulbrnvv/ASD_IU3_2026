## 1. Идея решения и структура данных
**Идея:** Однократный линейный проход по массиву с одновременным обновлением текущего минимального и максимального значений.

**Структура данных:** Стандартный одномерный массив `int[]`. Позволяет обращаться к элементам по индексу за $O(1)$, что обеспечивает оптимальную скорость обработки данных.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
for (int i = 0; i < n; i++) {
    if (array[i] < min) {
        min = array[i];
    }
    if (array[i] > max) {
        max = array[i];
    }
}
```
Внешний цикл выполняется ровно $n$ раз, внутри выполняются операции сравнения за $O(1)$. 
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных).
## 3. Ручные тесты
1. Произвольный массив с разными числами.
* Вход: 4 | 10 3 20 5
* Выход: 3 20
* Значимость: Проверяет базовую корректность нахождения минимального и максимального элементов.
2. Массив с одинаковыми элементами:
* Вход: 3 | 7 7 7
* Выход: 7 7
* Значимость: Проверяет устойчивость алгоритма при отсутствии изменения граничных значений.
