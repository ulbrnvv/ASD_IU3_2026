# Отчет по задаче 49: Сумма строк матрицы
## 1. Идея решения и структура данных

**Идея:** Двухэтапный обход двумерного массива. Внешний цикл последовательно перебирает строки матрицы, а внутренний цикл проходит по всем элементам текущей строки, накапливая их сумму. Для каждой строки результат записывается в соответствующий элемент результирующего одномерного массива сумм.

**Структура данных:** Двумерный массив `int[][]` для хранения матрицы и одномерный массив `int[]` для сохранения сумм по каждой строке. Обеспечивают прямой доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n \times m)$

Обоснование на основе кода:
```java
int[] rowSums = new int[n];
    for (int i = 0; i < n; i++) {
        int currentSum = 0;
        for (int j = 0; j < m; j++) {
            currentSum += matrix[i][j];
        }
        rowSums[i] = currentSum;
}
```
Внешний цикл выполняется $n$ раз (по количеству строк), а внутренний — $m$ раз (по количеству столбцов в каждой строке). Общее количество итераций равно произведению размеров матрицы $n \times m$, что соответствует асимптотике $O(n \times m)$.
Дополнительная память: $O(n)$ для хранения результирующего массива сумм строк (помимо самой матрицы).
## 3. Ручные тесты
1. Прямоугольная матрица со смешанными числами:
* Вход: 2 3 | 1 2 3 | 4 5 6
* Выход: 6 15
* Значимость: Проверяет корректность суммирования элементов в строках прямоугольной матрицы разной размерности.
2. Массивы со смешанными знаками:
* Вход: 2 2 | -1 5 | 0 -3
* Выход: 4 -3
* Значимость: Проверяет правильность обработки отрицательных чисел и нулей при вычислении сумм строк.
