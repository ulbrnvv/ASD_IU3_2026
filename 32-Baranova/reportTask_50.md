# Отчет по задаче 50: Сумма столбцов матрицы
## 1. Идея решения и структура данных

**Идея:** Двухэтапный обход двумерного массива по столбцам. Внешний цикл последовательно перебирает индексы столбцов, а внутренний цикл проходит по всем строкам матрицы для текущего столбца, накапливая сумму его элементов. Для каждого столбца результат записывается в соответствующий элемент результирующего одномерного массива.

**Структура данных:** Двумерный массив `int[][]` для хранения матрицы и одномерный массив `int[]` для сохранения сумм по каждому столбцу. Обеспечивают прямой доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n \times m)$

Обоснование на основе кода:
```java
int[] colSums = new int[m];
for (int j = 0; j < m; j++) {
    int currentSum = 0;
    for (int i = 0; i < n; i++) {
        currentSum += matrix[i][j];
    }
    colSums[j] = currentSum;
}
```
Внешний цикл выполняется $m$ раз (по количеству столбцов), а внутренний — $n$ раз (по количеству строк). Общее количество итераций равно произведению размеров матрицы $n \times m$, что соответствует асимптотике $O(n \times m)$.
Дополнительная память: $O(m)$ для хранения результирующего массива сумм столбцов (помимо самой матрицы).
## 3. Ручные тесты
1. Прямоугольная матрица со смешанными числами:
* Вход: 2 3 | 1 2 3 | 4 5 6
* Выход: 5 7 9
* Значимость: Проверяет корректность вертикального суммирования элементов в столбцах прямоугольной матрицы.
2. Массивы со смешанными знаками:
* Вход: 2 2 | -1 5 | 0 -3
* Выход: -1 2
* Значимость: Проверяет правильность обработки отрицательных чисел и нулей при вычислении сумм столбцов.
