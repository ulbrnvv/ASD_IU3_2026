# Отчет по задаче 25: Сумма элементов
## 1. Идея решения и структура данных

**Идея:** Однократный линейный проход по массиву слева направо с последовательным суммированием каждого элемента в накопительную переменную. Для предотвращения переполнения разрядной сетки при сложении больших чисел используется тип `long`.

**Структура данных:** Стандартный одномерный массив `int[]`. Обеспечивает эффективный доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
long sum = 0;
for (int i = 0; i < n; i++) {
    sum += array[i];
}
```
Алгоритм совершает ровно один цикл по всем $n$ элементам массива. Операции сложения и доступа по индексу выполняются за константное время $O(1)$, что суммарно дает линейную временную сложность.Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для хранения суммы и индекса).
## 3. Ручные тесты
1. Массив с положительными и отрицательными числами:
* Вход: 4 | 10 -5 20 3
* Выход: 28
* Значимость: Проверяет базовую корректность суммирования со смешанными знаками.
2. Массив с нулями и отрицательными значениями:
* Вход: 3 | 0 -10 -20
* Выход: -30
* Значимость: Проверяет корректность работы накопителя суммы при отрицательных результатах.
