# Отчет по задаче 12: Пара с заданной суммой
## 1. Идея решения и структура данных

**Идея:** Полный перебор всех возможных пар индексов $(i, j)$ таких, что $0 \le i < j < n$. Для каждой пары проверяется условие равенства суммы элементов заданному числу $s$ ($a_i + a_j = s$). Поскольку требуется найти пару с наименьшим индексом $i$, а при равенстве — с наименьшим $j$, вложенные циклы запускаются последовательно слева направо. При первом нахождении подходящей комбинации индексы фиксируются и возвращаются. Если ни одной подходящей пары не обнаружено, возвращаются значения `-1 -1`.

**Структура данных:** Стандартный одномерный массив `int[]`. Обеспечивает прямой доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n^2)$

Обоснование на основе кода:
```java
int index1 = -1;
int index2 = -1;
boolean found = false;

for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        if (array[i] + array[j] == s) {
            index1 = i;
            index2 = j;
            found = true;
            break;
        }
    }
    if (found) {
        break;
    }
}
```
В алгоритме используются два вложенных цикла. Внешний цикл выполняется $n$ раз, а внутренний зависит от текущего шага внешнего и в сумме совершает $\frac{n(n-1)}{2}$ итераций. Это соответствует квадратичной асимптотической сложности $O(n^2)$.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для хранения индексов, флага и целевой суммы).
## 3. Ручные тесты
1. Существующая пара элементов:
* Вход: 4 8 | 2 5 3 6
* Выход: 1 2
* Значимость: Проверяет корректность нахождения и возврата правильных индексов первой подходящей пары.
2. Отсутствие пары с заданной суммой:
* Вход: 3 10 | 1 2 3
* Выход: -1 -1
* Значимость: Проверяет граничный случай, когда в массиве нет двух элементов, дающих в сумме $s$, и программа корректно возвращает -1 -1.
