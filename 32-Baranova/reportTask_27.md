# Отчет по задаче 27: Сумма квадратов
## 1. Идея решения и структура данных

**Идея:** Однократный линейный проход по массиву слева направо. Для каждого элемента вычисляется его квадрат, после чего значения суммируются в накопительной переменной. Поскольку квадраты целых чисел могут быстро расти, для предотвращения переполнения разрядной сетки используется тип `long`.

**Структура данных:** Стандартный одномерный массив `int[]`. Обеспечивает эффективный доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
long sumOfSquares = 0;
for (int i = 0; i < n; i++) {
    sumOfSquares += (long) array[i] * array[i];
}
```
Алгоритм совершает ровно один цикл по всем $n$ элементам массива. Операции приведения типов, умножения и сложения выполняются за константное время $O(1)$, что суммарно дает линейную временную сложность.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для хранения суммы квадратов и индекса).
## 3. Ручные тесты
1. Массив с положительными и отрицательными числами:
* Вход: 3 | 1 -2 3
* Выход: 14
* Значимость: Проверяет корректность возведения в квадрат отрицательных чисел (отрицательный знак убирается).
2. Массив из нулей:
* Вход: 3 | 0 0 0
* Выход: 0
* Значимость: Проверяет граничный случай с нулевыми значениями элементов.
