# Отчет по задаче 26: Произведение элементов
## 1. Идея решения и структура данных

**Идея:** Последовательное умножение элементов массива с взятием остатка по модулю $10^9 + 7$ на каждой итерации. Это необходимо для предотвращения переполнения разрядной сетки (overflow) при работе с большими числами.

**Структура данных:** Стандартный одномерный массив `int[]`. Обеспечивает эффективный доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
long product = 1;
long MOD = 1_000_000_007;
for (int i = 0; i < n; i++) {
    product = (product * (array[i] % MOD)) % MOD;
}
```
Алгоритм совершает один линейный проход по всем $n$ элементам массива. Операции умножения и взятия остатка выполняются за константное время $O(1)$, что суммарно дает линейную временную сложность.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для хранения текущего произведения, модуля и индекса).
## 3. Ручные тесты
1. Массив с небольшими числами:
* Вход: 3 | 2 3 4
* Выход: 24
* Значимость: Проверяет базовую корректность вычисления произведения.
2. Массив, содержащий нули:
* Вход: 3 | 5 0 10
* Выход: 0
* Значимость: Проверяет корректность обработки нулевого элемента (произведение должно моментально обнуляться).
