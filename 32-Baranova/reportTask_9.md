# Отчет по задаче 9: Проверка отсортированности
## 1. Идея решения и структура данных
**Идея:** Последовательное попарное сравнение соседних элементов массива (`array[i]` и `array[i + 1]`) слева направо. Если обнаруживается нарушающий порядок элемент (где предыдущий строго больше следующего), проверка прекращается и возвращается результат `NO`. Если цикл завершается без нарушений, выводится `YES`.

**Структура данных:** Стандартный одномерный массив `int[]`. Обеспечивает эффективный доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$ в худшем случае / $O(1)$ в лучшем случае

Обоснование на основе кода:
```java
boolean isSorted = true;
for (int i = 0; i < n - 1; i++) {
    if (array[i] > array[i + 1]) {
        isSorted = false;
        break;
    }
}
```
В худшем случае (когда массив полностью отсортирован или нарушение порядка находится в самом конце) цикл выполняет $n - 1$ итераций, что дает линейную сложность $O(n)$. В лучшем случае (если нарушение порядка найдено на первых элементах) благодаря оператору break цикл завершается досрочно за $O(1)$.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для флага и счетчика).
## 3. Ручные тесты
1. Отсортированный неубывающий массив:
* Вход: 4 | 1 2 2 5
* Выход: YES
* Значимость: Проверяет корректность подтверждения неубывающего порядка, включая наличие равных соседних элементов.
2. Неотсортированный массив с нарушением порядка:
* Вход: 4 | 1 3 2 4
* Выход: NO
* Значимость: Проверяет работу досрочного прерывания цикла (break) при обнаружении падения значения (3 > 2).
