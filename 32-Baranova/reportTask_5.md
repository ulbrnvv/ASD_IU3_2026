# Отчет по задаче 5: Сумма элементов на чётных позициях
## 1. Идея решения и структура данных
**Идея:** Обход элементов одномерного массива с шагом 2 по индексам (`0, 2, 4` и т. д.) для суммирования элементов, расположенных на чётных позициях.

**Структура данных:** Стандартный одномерный массив `int[]`. Позволяет обращаться к элементам по индексам за $O(1)$, что обеспечивает эффективный проход по позициям с заданным шагом.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
long sum = 0;
for (int i = 0; i < n; i += 2) {
    sum += array[i];
}
```
Цикл с шагом i += 2 выполняется примерно $n / 2$ раз, что после отбрасывания константы дает линейную временную сложность $O(n)$. Внутри цикла операции сложения и доступа по индексу выполняются за $O(1)$.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для накопителя суммы и счетчика индекса).
## 3. Ручные тесты
1. Массив чётной длины:
* Вход: 4 | 10 20 30 40
* Выход: 40
* Значимость: Проверяет корректность суммирования четных позиций при четном размере массива.
2. Массив нечётной длины:
* Вход: 5 | 5 10 15 20 25
* Выход: 45
* Значимость: Проверяет корректность обработки последнего элемента на четной позиции при нечетной длине массива.
