# Отчет по задаче 4: Все индексы элемента
## 1. Идея решения и структура данных
**Идея:** Последовательный проход по массиву слева направо с проверкой каждого элемента на равенство искомому значению `x`. При обнаружении совпадения текущий индекс сохраняется в динамический список для последующего вывода в порядке возрастания.

**Структура данных:** Стандартный одномерный массив `int[]` для входных данных и `ArrayList<Integer>` для динамического накопления найденных индексов, так как их общее количество заранее неизвестно.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
List<Integer> indices = new ArrayList<>();
for (int i = 0; i < n; i++) {
    if (array[i] == x) {
        indices.add(i);
    }
}
```
Алгоритм выполняет ровно один линейный проход по всем $n$ элементам массива. Операции сравнения и добавления элементов в список (в среднем) выполняются за константное время $O(1)$.
Дополнительная память: $O(k)$, где $k$ — количество найденных вхождений элемента в массиве (в худшем случае $O(n)$, если все элементы равны искомому).
## 3. Ручные тесты
1. Элемент присутствует в массиве несколько раз на разных позициях:
* Вход: 5 5 | 10 5 20 5 30 | 5
* Выход: 1 3
* Значимость: Проверяет корректность сбора и вывода всех индексов в порядке возрастания при множественных вхождениях.
2. Элемент отсутствует в массиве:
* Вход: 4 2 | 1 2 3 4 | 99
* Выход: (пустая строка / отсутствие вывода индексов)
* Значимость: Проверяет граничный случай, когда элемент не найден, и список индексов остается пустым.
