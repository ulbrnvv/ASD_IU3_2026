# Отчет по задаче 3: Подсчет вхождений
## 1. Идея решения и структура данных
**Идея:** Линейный перебор элементов массива слева направо с инкрементом счетчика при каждом совпадении текущего элемента с искомым значением `x`.

**Структура данных:** Стандартный одномерный массив `int[]`. Позволяет обращаться к элементам по индексу за $O(1)$, что обеспечивает оптимальную скорость обработки данных.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
int count = 0;
for (int i = 0; i < n; i++) {
        if (array[i] == x) {
            count++;
        }
}
```
В алгоритме используется один цикл, который выполняется ровно $n$ раз (по количеству элементов массива). Все операции сравнения и инкремента выполняются за константное время $O(1)$.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для счетчика и искомого значения).
## 3. Ручные тесты
1. Элемент присутствует в массиве несколько раз:
* Вход: 5 2 | 10 20 10 30 10 | 10
* Выход: 3
* Значимость: Проверяет корректность возврата индекса именно первого вхождения элемента.
2. Элемент отсутствует в массиве:
* Вход: 4 2 | 1 2 3 4 | 99
* Выход: 0
* Значимость: Проверяет граничный случай, когда искомый элемент не найден, и счетчик корректно остается равным 0.
