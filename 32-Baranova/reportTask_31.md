# Отчет по задаче 31: Скалярное произведение
## 1. Идея решения и структура данных

**Идея:** Синхронный линейный проход по двум одинаковым массивам слева направо. На каждом шаге перемножаются элементы с одинаковыми индексами ($a_i \times b_i$), после чего результаты суммируются в накопительной переменной. Для предотвращения переполнения разрядной сетки при суммировании произведений используется тип `long`.

**Структура данных:** Два стандартных одномерных массива `int[]`. Обеспечивают эффективный прямой доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
long scalarProduct = 0;
for (int i = 0; i < n; i++) {
    scalarProduct += (long) arrayA[i] * arrayB[i];
}
```
Алгоритм совершает ровно один цикл по всем $n$ элементам обоих массивов. Операции приведения типов, умножения и сложения выполняются за константное время $O(1)$, что суммарно дает линейную временную сложность.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для хранения суммы скалярного произведения и индекса).
## 3. Ручные тесты
1. Массивы с положительными числами:
* Вход: 3 | 1 2 3 | 4 5 6
* Выход: 32
* Значимость: Проверяет базовую корректность вычисления скалярного произведения векторов.
2. Массивы со смешанными знаками:
* Вход: 2 | 2 -3 | -4 5
* Выход: -23
* Значимость: Проверяет правильность обработки отрицательных знаков при перемножении и сложении.
