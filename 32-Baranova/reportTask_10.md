# Отчет по задаче 10: Поиск элемента с условием
## 1. Идея решения и структура данных
**Идея:** Линейный проход по массиву слева направо с проверкой каждого элемента на кратное деление заданному числу `k` (остаток от деления `array[i] % k == 0`). При обнаружении подходящего элемента его индекс сохраняется в переменную. Поскольку требуется найти *последний* такой элемент, поиск продолжается до конца массива, перезаписывая индекс при каждом новом совпадении. Если кратных элементов не найдено, возвращается `-1`.

**Структура данных:** Стандартный одномерный массив `int[]`. Обеспечивает эффективный доступ к элементам по индексам за $O(1)$.

## 2. Анализ асимптотики
**Временная сложность:** $O(n)$

Обоснование на основе кода:
```java
int lastIndex = -1;
for (int i = 0; i < n; i++) {
    if (array[i] % k == 0) {
        lastIndex = i;
    }
}
```
Алгоритм совершает один линейный проход по всем $n$ элементам массива. Операции взятия остатка, сравнения и сохранения индекса выполняются за константное время $O(1)$, что суммарно дает линейную сложность.
Дополнительная память: $O(1)$ (используется фиксированное число скалярных переменных для хранения последнего индекса и параметра k).
## 3. Ручные тесты
1. Массив с несколькими кратными элементами:
* Вход: 5 3 | 10 6 20 9 25
* Выход: 3
* Значимость: Проверяет корректность перезаписи индекса и гарантирует, что возвращается именно последнее вхождение кратного элемента.
2. Отсутствие кратных элементов в массиве:
* Вход: 4 5 | 1 2 3 4
* Выход: -1
* Значимость: Проверяет граничный случай, когда в массиве нет элементов, кратных k, и программа корректно возвращает -1.
